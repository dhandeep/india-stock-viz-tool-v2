FIFO lot ledger for ICICI Direct equity exports

required optional

Load your ICICI Direct files

Your files stay on this computer. They are read inside this browser tab. Nothing is uploaded, and this page makes no network requests.

  1. 1. Transactions CSV

    Required Not loaded

    In ICICI Direct, go to Portfolio › Equity › All Transactions, set the date range to start before your first ever trade, and download it as CSV. Use the file as downloaded, without editing it.

    Columns this file must have

    Stock Symbol, Company Name, ISIN Code, Action (Buy / Sell), Quantity, Transaction Price, Transaction Date (e.g. 22-Jul-2013).
    Used when present: Brokerage, Transaction Charges, StampDuty (added to cost), Remarks (marks bonus, demerger and reconciliation lots).

    A missing early history shows up as an error ("sell exceeds open quantity"), never as a silently wrong ledger.

  2. 2. Holdings CSV

    Optional Not loaded

    Lets the app check its results against ICICI's own figures: quantity, value at cost and realised P&L per stock. Make it from ICICI Direct's Portfolio › Equity holdings page, one row per stock, with exactly these columns:

    ISIN Code, Qty, Value At Cost, Realized Profit / Loss (numbers may contain commas; losses as -123 or (123))

  3. 3. As-of date

    The date used to measure holding periods (long-term means held more than 12 months). Defaults to today.

You can also drop both files anywhere on this page; the holdings file is recognised by its header. Just looking?
